# Contributing to the Grundschutz++ Explorer website

[Deutsch](#deutsch) · [English](#english)

---

## Deutsch

Vielen Dank für Ihr Interesse an der Projektwebseite des Grundschutz++ Explorers!

Die Webseite ist Open Source, **nimmt derzeit aber keine Code-Beiträge an**.
Sie wird, wie die App, von einer einzelnen Person entwickelt und gepflegt. Deshalb werden
**Pull Requests derzeit nicht angenommen** und ohne Prüfung geschlossen.
Bitte nehmen Sie das nicht persönlich, so bleibt das Projekt überschaubar.

### Was willkommen ist

- **Fehlermeldungen zur Webseite:** Eröffnen Sie ein Issue mit der betroffenen Stelle,
  Ihrem Browser und dessen Version sowie, falls hilfreich, einem Screenshot.
- **Fehler im Text:** Tippfehler, veraltete Angaben oder unklare Formulierungen
  können ebenfalls als Issue gemeldet werden.

Fehler und Vorschläge **zur App selbst** gehören in das Repository der App:
[fwdotcom/grundschutz-explorer](https://github.com/fwdotcom/grundschutz-explorer/issues).
Sicherheitslücken melden Sie bitte vertraulich über
[GitHub Security Advisories](https://github.com/fwdotcom/grundschutz-explorer/security/advisories/new).

### Forks

Die Lizenz erlaubt es ausdrücklich, die Webseite zu forken und für eigene Zwecke anzupassen.
Es gibt keinen Build-Schritt: Stellen Sie das Verzeichnis `www/` mit einem beliebigen
statischen Webserver bereit. Bitte ersetzen Sie dabei Impressum, Datenschutzerklärung und
alle Verweise auf die Adresse `grundschutz-explorer.de` durch eigene Angaben.

## English

Thank you for your interest in the Grundschutz++ Explorer website!

The website is open source, but **currently not open to code contributions**.
Like the app, it is developed and maintained by a single author. For that reason,
**pull requests are currently not accepted** and will be closed without review.
Please don't take this personally, it keeps the project manageable.

### What is welcome

- **Bug reports about the website:** Open an issue describing the affected part,
  your browser and its version and, if helpful, a screenshot.
- **Text errors:** Typos, outdated information or unclear wording can be
  reported as issues as well.

Bugs and suggestions **concerning the app itself** belong in the app repository:
[fwdotcom/grundschutz-explorer](https://github.com/fwdotcom/grundschutz-explorer/issues).
Please report security vulnerabilities privately via
[GitHub Security Advisories](https://github.com/fwdotcom/grundschutz-explorer/security/advisories/new).

### Forks

The license explicitly allows you to fork and adapt the website for your own needs.
There is no build step: serve the `www/` directory with any static web server.
Please replace the legal notice (Impressum), the privacy policy and all references
to `grundschutz-explorer.de` with your own details.
